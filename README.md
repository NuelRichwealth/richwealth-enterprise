# Christ Embassy Kumasi Airport Youth Church

A simple static church management dashboard for member records, attendance tracking, church offerings, and monthly reports.

## Project structure

- `index.html` – dashboard landing page
- `members.html` – member directory and registration form
- `attendance.html` – attendance tracking page
- `offerings.html` – offerings and donations page
- `reports.html` – ministry and church summary reports
- `css/style.css` – shared styling
- `js/*.js` – page-specific JavaScript behavior
- `images/` – uploaded logo and images
- `vercel.json` – Vercel deployment configuration

## Run locally

From this project folder, you can open the HTML files directly in a browser, or run a lightweight local server:

```bash
npx serve .
```

Then open the local URL displayed in the terminal.

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repo in Vercel.
3. Keep the default settings.
4. Deploy.

## Branding

The project is branded for Christ Embassy Kumasi Airport Youth Church and uses the church logo from the `images` folder.
